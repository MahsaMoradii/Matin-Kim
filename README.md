# فروشگاه لباس Matin Kim 👕

این پروژه یک نمونه بازطراحی (Clone) از وب‌سایت برند کره‌ای **Matin Kim** است که با هدف تمرین طراحی رابط کاربری، پیاده‌سازی صفحات ریسپانسیو و افزایش مهارت در توسعه فرانت‌اند ساخته شده است.

## ✨ ویژگی‌ها

- طراحی مدرن و مینیمال
- کاملاً ریسپانسیو (مناسب موبایل، تبلت و دسکتاپ)
- منوی ناوبری تعاملی
- اسلایدر تصاویر
- افکت‌ها و انیمیشن‌های جذاب
- رابط کاربری روان و کاربرپسند
- کدنویسی منظم و قابل توسعه

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 ساختار پروژه

```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```
## 📱 طراحی ریسپانسیو

- 📱 تبلت
